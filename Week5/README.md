# Week 5 - Authentication and Role-Based Backend System

This week focuses on backend authentication, authorization, middleware handling, API development, and MongoDB model integration using Node.js and Express.js.

---

## Folder Structure

### APIs
Contains all API routes for different user roles and functionalities.

Files:
- adminApi.js
- authorApi.js
- commonApi.js
- userApi.js

Concepts Covered:
- REST API development
- Role-based APIs
- Route handling
- User and admin operations
- API modularization

---

### MiddleWare
Contains middleware functions used for authentication and authorization.

Files:
- checkAuthor.js
- verifyToken.js

Concepts Covered:
- JWT token verification
- Authorization middleware
- Route protection
- Access control

---

### models
Contains MongoDB schema models for the application.

Files:
- articleModel.js
- userModel.js

Concepts Covered:
- Mongoose schemas
- Database modeling
- User and article data management

---

### services
Contains reusable service functions related to authentication.

Files:
- authService.js

Concepts Covered:
- Authentication services
- Token generation
- Business logic separation
- Reusable backend services
